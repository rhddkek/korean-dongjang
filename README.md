# 동장의 난

내가 사는 동에서 동장으로 시작해 구청장·시장·도지사·대통령까지 오르는 턴제 땅따먹기 웹게임입니다.
실제 행정동 지도와 인구·상권 통계로 동네마다 힘이 다릅니다. 단일 HTML 파일 하나로 돌아가고, 저장은 브라우저에 남습니다.

**플레이:** https://rhddkek.github.io/korean-dongjang/

## 모드

- 서울 427개 동, 광역시 6곳(부산·대구·인천·광주·대전·울산)
- 도 지역(경기·강원·충북·충남·전북·경북·경남·제주), 통합 모드(대구경북·경상도·전남광주·전라도), 전국(시군구 단위)

## 한 판의 흐름

1. 시작할 동을 고르고 옆 동네를 공격하거나 돈으로 설득합니다.
2. 개발(상권·교통·주거·치안)에는 대가가 있습니다.
3. 다른 세력의 동에는 공격 말고 공작도 걸 수 있습니다. 이간질(이웃 세력끼리 3달 싸움), 내부 포섭(안 맞닿은 동도 싸우지 않고 가져옴), 내분 조장(세력 일부 독립), 여론전(한 구의 세력 동 민심 급락). 성공률은 우리 치안 개발·상대 성향·최근 공작 횟수로 정해지고, 들키면 대가가 있습니다. 상대도 우리 동을 포섭하려 하며 치안이 높으면 막습니다.
4. 세력마다 성향이 있습니다. 공격형은 방어가 약하고, 부자형은 포섭비가 2배, 결속형은 포섭·내분이 안 통하는 대신 무너지면 동이 통째로 넘어옵니다. 한 달에 같은 세력을 두 번 넘게 치면 보복을 예고합니다.
5. 본거지를 잃거나 동이 4곳 이하로 줄면 3달 동안 재기의 기회(모집 2배·설득 할인·공작 성공률↑)가 옵니다. 12달 동안 5곳을 못 넘기면 패배입니다.
6. 달마다 이달 과제가 하나 나옵니다(동 얻기, 구 절반 넘기기, 개발, 예고된 동 지키기). 해내면 예산 보상이 있고, 연달아 해내면 보상이 10%씩 커집니다(최대 +50%).
7. 승진할 때와 반년마다 정책 카드를 고르고, 구청장부터는 이어진 동을 묶어 이름 붙인 행정구역을 만들고 합병할 수 있습니다. 권역장부터는 구역을 괴뢰국으로 독립시켜 상납을 받고, 공격·방어·개발 방침과 공격 대상을 명령할 수 있습니다.
8. 인구 45%를 넘기면 남은 세력이 반동장 연합을 맺습니다. 각 세력의 회장은 우리를 기억하고, 무너지면 다른 세력의 고문으로 돌아옵니다.
9. 인구 60%를 넘기면 3달 뒤 선거입니다. 공약 두 개를 고르고 구마다 유세해 과반을 얻으면 당선입니다. 55%를 넘겼는데 남은 세력이 모두 작으면 조기 선거가 열립니다. 판이 기운 뒤 큰 세력을 무너뜨리면 작은 세력들이 연쇄 투항하고, 승진 뒤에는 동장실의 자동 진행으로 사건이 날 때까지 달을 넘길 수 있습니다.
10. 판이 끝나면 땅을 넓혀 온 기록을 처음부터 다시 볼 수 있습니다. 시작 화면의 오늘의 도전은 날짜마다 모두 같은 시작 동·같은 판이고, 이긴 시작 동은 도감(지도의 노란 동)과 칭호로 쌓입니다. 다른 유형 동에서 이기면 그 대표 능력을 어디서든 고를 수 있습니다.

## 개발

- 규칙: `src/engine.js` · 화면: `src/ui.js` · 틀: `src/index.tpl.html`
- 데이터: `data/game_data.json`(서울), `data/city_*.json`(광역시·도·통합·전국), 만드는 스크립트 `tools/build_modes.py`
- 배경음악: `bgm/calm.mp3`, `bgm/tense.mp3` (메뉴에서 켰을 때만 불러옴, 원본은 `raw/bgm/src`)
- 빌드: `python3 tools/build.py` → `dongjang.html`(단일 파일)과 `index.html`(GitHub Pages용, 미리보기 태그 포함)
- 테스트: `node tools/test2.js` ~ `test19.js <스크린샷폴더>` (Playwright, 휴대폰 화면), `node tools/play2.js`
- 자동 플레이 균형: `node tools/simmodes.js`
