# 동장의 난

내가 사는 동에서 동장으로 시작해 구청장·시장·도지사·대통령까지 오르는 턴제 땅따먹기 웹게임입니다.
실제 행정동 지도와 인구·상권 통계로 동네마다 힘이 다릅니다. 단일 HTML 파일 하나로 돌아가고, 저장은 브라우저에 남습니다.

**플레이:** https://rhddkek.github.io/korean-dongjang/

## 모드

- 서울 427개 동, 광역시 6곳(부산·대구·인천·광주·대전·울산)
- 도 지역(경기·강원·충북·충남·전북·경북·경남·제주), 통합 모드(대구경북·경상도·전남광주·전라도), 전국(시군구 단위)

## 한 판의 흐름

1. 시작할 동을 고르고 옆 동네를 공격하거나 돈으로 설득합니다.
2. 개발(상권·교통·주거·치안)에는 대가가 있습니다.
3. 승진할 때와 반년마다 정책 카드를 고르고, 구청장부터는 이어진 동을 묶어 이름 붙인 행정구역을 만들 수 있습니다.
4. 인구 45%를 넘기면 남은 세력이 반동장 연합을 맺습니다. 각 세력의 회장은 우리를 기억하고, 무너지면 다른 세력의 고문으로 돌아옵니다.
5. 인구 60%를 넘기면 3달 뒤 선거입니다. 공약 두 개를 고르고 구마다 유세해 과반을 얻으면 당선입니다.
6. 판이 끝나면 땅을 넓혀 온 기록을 처음부터 다시 볼 수 있습니다.

## 개발

- 규칙: `src/engine.js` · 화면: `src/ui.js` · 틀: `src/index.tpl.html`
- 데이터: `data/game_data.json`(서울), `data/city_*.json`(광역시·도·통합·전국), 만드는 스크립트 `tools/build_modes.py`
- 빌드: `python3 tools/build.py` → `dongjang.html`(단일 파일)과 `index.html`(GitHub Pages용, 미리보기 태그 포함)
- 테스트: `node tools/test2.js` ~ `test19.js <스크린샷폴더>` (Playwright, 휴대폰 화면), `node tools/play2.js`
- 자동 플레이 균형: `node tools/simmodes.js`
